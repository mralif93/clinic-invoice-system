Malaysian SST Act 2018 Healthcare Compliance

Service Tax Regulations 2018 (First Schedule, Healthcare Category)

Official Statutory Standard
0% SST (Tax Exempt)

Medical consultations, doctor diagnostic procedures, surgical dressing, blood screening, and prescription pharmaceuticals are legally exempt.

6% / 8% Taxable Items

Elective cosmetics, OTC supplements, health wellness retail items, or non-clinical wellness services can be configured with standard SST rates.

System Blueprint

Enterprise Architecture Modules

Module 1: Patient Directory

Search records by Malaysian IC, Passport, or mobile. Real-time allergy warnings and historical debt tracking.

Module 2: Item & Drug Master

Centralized pricing for Consultations, Procedures, Diagnostics, and Dispensary pharmaceuticals with stock deducts.

Module 3: POS Invoicing Engine

Dynamic formula calculation: Total = (Qty × Rate) - Disc + SST. Full lifecycle from Draft to Settled or Void.

Module 4: Multi-Channel Tender

Fast front-desk cashier reconciliation supporting Cash, Credit/Debit EDC terminals, DuitNow QR, and Insurance Panel guarantees.

Module 5: Cash Drawer Float

Daily cash drawer count balance vs. recorded collections with automated variance logging and shift closure tallies.

Module 6: Governance & Audit Logs

100% immutable audit logging capturing actor, timestamp, IP address, and payload snapshots on every invoice void.

Deploy & Run Locally

Get up and running in 3 minutes with PHP 8.2+ and Composer

git clone 50-Record Seeders 
# 1. Clone repository
git clone https://github.com/mralif93/clinic-invoice-system.git
cd clinic-invoice-system/cis

# 2. Install dependencies & configure environment
composer install
npm install
cp .env.example .env
php artisan key:generate

# 3. Migrate and seed 50 sample clinical records
php artisan migrate:fresh --seed

# 4. Build assets and launch POS server
npm run build
php artisan serve --port=8001
